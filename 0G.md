# Requirements 

For teams iterating on an existing 0G project started at ETHGlobal Cannes, the online agent hackathon, Zero Cup, or independent prior work. We are not judging polish on old demos. We are judging meaningful progress during the Lisbon hackathon window: new features, production hardening, user readiness, and trajectory toward real usage.

Ideas to get you started:

🔹 Evolve a Cannes or online-hackathon prototype into a deployed product with persistent 0G Storage memory and on-chain settlement on 0G Chain 🔹 Harden an existing project with verifiable inference on 0G Compute, error recovery, and robust state management 🔹 Integrate a missing stack layer: move inference to 0G Compute, memory to 0G Storage, or identity to an Agentic ID,

Qualification Requirements
Submission requirements: 🔹 Project name and a short description 🔹 Contract deployment addresses 🔹 Public GitHub repo (README + setup instructions) 🔹 Demo video & live demo link (keep the video under 3 mins!) 🔹 Explain which 0G features or SDKs you used 🔹 Team member names and contact info (Telegram & X)

Additional requirements for Continuity (on top of standard rules): 🔹 Link to prior state: a dated commit hash or the previous ETHGlobal submission page marking where you started 🔹 Dated changelog of work done during the Lisbon hackathon window 🔹 Short "What's next" statement to show trajectorygo
