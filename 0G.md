# Orloj × 0G

> *Built at **ETHGlobal Lisbon 2026**.* Agent inference on 0G Compute, and a curated skills marketplace on 0G Storage.

## The pitch

0G is the core provider behind the feature we introduced at ETHGlobal Lisbon: **Orloj Agents**. Until now Orloj was infrastructure — it turned Sourcify-verified contracts into MCP servers and signed for them through HSM-backed KMS keys the user controls, but a developer had to bring their own agent. Orloj Agents closes that gap: the app now ships a full chat interface where a user picks which Orloj MCPs an agent may call, then talks to it directly.

0G supplies both halves of what that agent is made of:

- **0G Compute** is the inference provider — the only model provider the agent runtime declares.
- **0G Storage** supplies expertise and its authenticity. Skills are markdown expertise packs, each a content-addressed blob on 0G Storage mainnet, discoverable through a published index.

Remove 0G and Orloj Agents does not degrade — it does not exist. There is no fallback provider and no local skill copy; the chat is a shell around 0G inference and 0G-hosted expertise.

## How we use 0G Compute

Every Orloj agent's reasoning is served by 0G's inference router. The agent runtime ([packages/zeroclaw-agents/default/config.toml](packages/zeroclaw-agents/default/config.toml)) declares exactly one model provider, and it is 0G:

```toml
[providers.models.custom.default]
model = "qwen3.7-max"
uri   = "https://router-api.0g.ai/v1"
api_key = ""                      # injected at runtime, never committed

[agents.default]
model_provider = "custom.default" # 0G is the default, not a fallback
runtime_profile = "unbounded"
```

**`qwen3.7-max` on 0G is what drives every agentic loop** — tool selection, argument construction, multi-step planning against the MCP tools Orloj exposes. These are long, tool-heavy agentic sessions, not single completions, so the inference provider is load-bearing under real agentic pressure, not just answering prompts.

## How we use 0G Storage

We built [packages/skills-marketplace](packages/skills-marketplace) — a publisher that puts curated agent skills on 0G Storage mainnet and records what it published in a committed, machine-readable index.

The catalog itself is also on 0G Storage, so discovery does not depend on our repo staying online. The current index root, its Flow transaction, and the network it was published to are recorded in [packages/skills-marketplace/marketplace.json](packages/skills-marketplace/marketplace.json) — rewritten by the publisher on every successful run, so it cannot drift from what is actually on chain.

Anyone holding that one root hash can reconstruct the entire marketplace from 0G Storage — every skill name, description, size, and per-file root — with no dependency on Orloj.
